**`convert()` override** (per D-06, D-07, D-08):
1. Get pipelineable data via `get_pipelineable_data()`. If nullptr, return false.
2. Get `const auto& batches = pipelineable->get_data_batches();`
3. Track `bool any_converted = false;`
4. For each `batch` in `batches`:
   a. Check if batch's memory_space matches any of target_spaces — if none match, skip this batch (D-06: only convert batches in a matching source space)
   b. Check `batch->get_state() == cucascade::batch_state::task_created` — if not, skip
   c. Save `auto prev_state = batch->get_state();`
   d. `if (!batch->try_to_lock_for_in_transit()) { continue; }` — skip if lock fails
   e. Try-catch block (per D-08 save/lock/convert/restore pattern):
      - `auto data_size = batch->get_data()->get_size_in_bytes();`
      - Iterate `target_spaces`: for each space, `auto reservation = res_mgr.request_reservation(cucascade::memory::specific_memory_space{space->get_tier(), space->get_id().device_id}, data_size);`
      - If no reservation, continue to next space
      - `auto* mem_space = res_mgr.get_memory_space(reservation->tier(), reservation->device_id());` — if nullptr, continue
      - `auto& converter_registry = sirius::converter_registry::get();`
      - Switch on `space->get_tier()`: HOST -> `batch->convert_to<cucascade::host_data_representation>(converter_registry, mem_space, stream);`, GPU -> `batch->convert_to<cucascade::gpu_table_representation>(converter_registry, mem_space, stream);`, default: continue
      - Restore state: `batch->try_to_release_in_transit(std::optional<cucascade::batch_state>{prev_state});`
      - `any_converted = true; break;` (break inner space loop, proceed to next batch)
      - If no space succeeded for this batch: `batch->try_to_release_in_transit(std::optional<cucascade::batch_state>{prev_state});` (restore, D-07)
   f. Catch block: `batch->try_to_release_in_transit(std::optional<cucascade::batch_state>{prev_state}); throw;` (D-07 failure safety)
5. Return `any_converted`.

NOTE: The predicate in `convert()` checks that each batch matches one of the SOURCE spaces (the spaces data is currently in) — these are the batches we want to convert FROM. The `target_spaces` parameter is the destination. We iterate batches whose `get_memory_space()` is NOT one of target_spaces (those already in target don't need conversion). Correction: actually, looking at convertible_data_batch::convert(), target_spaces is the destination. The batch is already somewhere (e.g., GPU). We want to convert it to one of target_spaces (e.g., HOST). So we should NOT filter by source space — just iterate all task_created batches and try to convert each to target. Skip batches already in a target space. Specifically: for each batch, if `batch->get_memory_space()` is in `target_spaces`, skip it (already at destination).
