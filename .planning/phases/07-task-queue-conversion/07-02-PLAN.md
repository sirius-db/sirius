**Creating test gpu_pipeline_task instances:**
To create a real `gpu_pipeline_task` for testing, you need:
1. A `gpu_pipeline_task_global_state` — construct with `nullptr` pipeline: `auto global = std::make_shared<sirius::pipeline::gpu_pipeline_task_global_state>(nullptr);`
2. A `gpu_pipeline_task_local_state` with operator_data containing data_batches:
   - Create data_batches via `make_numeric_batch()`
   - Set batch state to `task_created` via `batch->try_to_create_task()`
   - Wrap in `pipelineable_operator_data`: `auto op_data = std::make_unique<sirius::op::pipelineable_operator_data>(std::vector<std::shared_ptr<cucascade::data_batch>>{batch});`
   - Create local state: `auto local = std::make_unique<sirius::pipeline::gpu_pipeline_task_local_state>(std::move(op_data));`
3. Construct task: `auto task = std::make_unique<sirius::pipeline::gpu_pipeline_task>(task_id, std::vector<cucascade::shared_data_repository*>{}, std::move(local), global);`

**Test implementations:**

Test 1 — "RAII returns task to queue on destruction":
```
inspectable_mpsc<itask> queue;
auto batch = make_numeric_batch(*gpu_space, {1,2,3}, INT32);
auto task = make_test_gpu_task(1, {batch});
queue.push(std::move(task));  // queue size 1
{
  provider provider(queue);
  auto cd = provider.get_next_convertible(gpu_space, false);
  REQUIRE(cd != nullptr);
  REQUIRE(queue.is_empty());
  // cd destroyed here, task returned to queue
}
REQUIRE(queue.size() == 1);
```

Test 2 — "RAII returns task after successful convert":
```
Create queue, push GPU task with task_created batch.
Extract via provider. Call convert({host_space}).
REQUIRE convert returned true.
Destroy wrapper.
REQUIRE queue.size() == 1.
Pop task, verify batch is now in HOST tier.
```

Test 3 — "RAII returns task on exception":
```
inspectable_mpsc<itask> queue;
push GPU task. Extract via provider wrapper.
try { throw std::runtime_error("test"); } catch(...) {}
// wrapper still alive, destroy it normally
REQUIRE queue.size() == 1 after wrapper destroyed.
```

Test 4 — "non-gpu_pipeline_task skipped by predicate":
```
queue.push(std::make_unique<dummy_task>());
provider provider(queue);
auto cd = provider.get_next_convertible(gpu_space, false);
REQUIRE(cd == nullptr);
REQUIRE(queue.size() == 1);  // dummy task still there
```

Test 5 — "wrong memory_space skipped":
```
Push GPU task with batch in gpu_space (task_created).
provider.get_next_convertible(host_space, false) -> nullptr.
queue.size() == 1.
```

Test 6 — "wrong batch_state skipped":
```
Create batch in gpu_space but leave in idle state (don't call try_to_create_task).
Push task. provider.get_next_convertible(gpu_space, false) -> nullptr.
```

Test 7 — "matching task selected":
```
Create batch in gpu_space, set task_created.
Push task. provider.get_next_convertible(gpu_space, false) -> non-null.
queue is empty. Wrapper holds the task.
```

Test 8 — "convert GPU task to HOST":
```
Create batch in gpu_space, task_created. Push to queue.
Extract via provider. convert({host_space}, stream, mgr).
REQUIRE true.
REQUIRE batch->get_memory_space()->get_tier() == Tier::HOST.
REQUIRE batch->get_state() == batch_state::task_created.
```

Test 9 — "bytes_in_space returns correct size":
```
Create task with 2 GPU batches. Wrap in convertible_gpu_pipeline_task.
REQUIRE bytes_in_space(gpu_space) == batch1_size + batch2_size.
REQUIRE bytes_in_space(host_space) == 0.
```

Test 10 — "get_all_convertible extracts all matching":
```
Push 3 tasks with task_created GPU batches.
provider.get_all_convertible(gpu_space, false) -> vector of size 3.
REQUIRE queue.is_empty().
Destroy all wrappers.
REQUIRE queue.size() == 3.
```

Test 11 — "RAII on interrupted queue logs warning":
```
Create queue, push task, extract via provider.
queue.interrupt();
// Destroying wrapper now will attempt push(), which returns false.
// Wrapper destructor should log SIRIUS_LOG_WARN and destroy the task.
// This test verifies no crash/hang occurs.
REQUIRE queue.is_empty() after wrapper destroyed (task was destroyed, not pushed).
```
