# Plan 11-01 — GDB the AUDIT TEST_CASE attach-path SIGSEGV + Apply Targeted Fix

## Context

The `[mgpu-audit] per-GPU distribution on TPC-H Q1` TEST_CASE SIGSEGVs at `test_gpu_execution_tpch_mgpu_audit.cpp:200` (`REQUIRE_FALSE(disable_fallback->HasError())`). Catch2 reports SIGSEGV at the next assertion line, so the actual fault occurs during one of:

1. `con->Query("SET enable_duckdb_fallback = false;")` execution
2. Destruction of `attach`/`use_db` QueryResults that went out of scope at the end of `attach_integration_duckdb` (line 136)
3. State leak between DuckDB ATTACH (line 130) and the SET command (line 198)

This failure is **pre-existing** on the base branch — confirmed via 10-03's `git stash + MCP run + git stash pop` evidence. It predates v1.2 entirely. The path goes through `cpu_source_task` (DuckDB-attached data), NOT the parquet filter translation path that Phase 10-03's `translated_expression::owned_stream` fix covered.

## Hypotheses (one will be confirmed by gdb)

- **H-A: Sirius extension SET-handler.** `SET enable_duckdb_fallback = false` triggers a Sirius-side handler that may interact incorrectly with the just-completed ATTACH. Look for `enable_duckdb_fallback` in `src/sirius_extension.cpp`.
- **H-B: SiriusContext::QueryBegin/QueryEnd state leak.** The `attach` and `use_db` queries each trigger `QueryBegin` + `QueryEnd`. State carryover (operator IDs, scan_round_robin, _batch_gpu_affinity, downgrade_executors) may not reset cleanly across ATTACH boundaries.
- **H-C: env->resume() reinit corruption.** The 2-GPU env is acquired via `acquire_integration_env_for(2)` then `env->resume()` reinitializes the Sirius context. If a prior single-GPU TEST_CASE leaked state into the global `g_integration_env_2gpu`, the SET handler hits a stale/mismatched topology.
- **H-D: DuckDB ATTACH + Sirius extension binding race.** The ATTACH creates a new database namespace; the Sirius extension's per-connection state may not be migrated to the attached DB context.
- **H-E: unexpected.** GDB surfaces something not in A-D.
