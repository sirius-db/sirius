<objective>
Wire the downgrade executor into the GPU pipeline executor so it can reclaim memory when reservations fall short.

Purpose: When gpu_pipeline_executor gets a partial memory reservation, it currently just warns and proceeds. After this plan, it will call request_free_memory_and_wait on the downgrade executor to free GPU memory, retry the reservation up to 5 times, and only proceed with a partial reservation as a last resort. This directly implements PIPE-01, PIPE-02, and PIPE-03.

Output: Modified gpu_pipeline_executor with retry-with-downgrade loop, updated pipeline_executor and SiriusContext to plumb the downgrade_executor pointer through construction.

**gpu_pipeline_executor.cpp — retry loop (per D-01, D-02, D-03):**

In `manager_loop()`, replace the existing partial-reservation warning block (lines 108-117) with the retry-with-downgrade loop. The existing code is:
```cpp
} else if (reservation->size() != bytes_needs) {
  SIRIUS_LOG_WARN(
    "GPU Pipeline Executor: Acquired memory reservation does not match requested size for "
    "pipeline {} of {} bytes needed for task "
    "{}. Reservation size: {}",
    gpu_task->get_pipeline_id(),
    bytes_needs,
    gpu_task->get_task_id(),
    reservation->size());
}
```

Replace with:
```cpp
} else if (reservation->size() < bytes_needs && _downgrade_executor) {
  static constexpr int kMaxDowngradeRetries = 5;
  for (int attempt = 1; attempt <= kMaxDowngradeRetries; ++attempt) {
    size_t shortfall = bytes_needs - reservation->size();
    SIRIUS_LOG_DEBUG(
      "GPU Pipeline Executor: reservation shortfall {} bytes for pipeline {} task {}, "
      "requesting downgrade (attempt {}/{})",
      shortfall,
      gpu_task->get_pipeline_id(),
      gpu_task->get_task_id(),
      attempt,
      kMaxDowngradeRetries);

    reservation.reset();  // release partial reservation before requesting downgrade
    size_t freed = _downgrade_executor->request_free_memory_and_wait(shortfall);
    if (freed == 0) {
      SIRIUS_LOG_DEBUG(
        "GPU Pipeline Executor: downgrade freed 0 bytes, stopping retry for task {}",
        gpu_task->get_task_id());
      reservation = _memory_space->make_reservation(bytes_needs);
      break;
    }

    reservation = _memory_space->make_reservation(bytes_needs);
    if (!reservation) {
      SIRIUS_LOG_ERROR(
        "GPU Pipeline Executor: reservation failed after downgrade for task {}",
        gpu_task->get_task_id());
      break;
    }
    if (reservation->size() >= bytes_needs) break;
  }

  if (!reservation) {
    SIRIUS_LOG_ERROR(
      "GPU Pipeline Executor: Failed to acquire memory reservation after downgrade for task {}",
      gpu_task->get_task_id());
    if (_completion_handler) {
      _completion_handler->report_error(
        "GPU Pipeline Executor: Failed to acquire memory reservation after downgrade for task " +
        std::to_string(gpu_task->get_task_id()));
    }
    break;
  }
  if (reservation->size() < bytes_needs) {
    SIRIUS_LOG_WARN(
      "GPU Pipeline Executor: after {} downgrade attempts, reservation still partial "
      "({}/{} bytes) for pipeline {} task {} -- proceeding with partial reservation",
      kMaxDowngradeRetries,
      reservation->size(),
      bytes_needs,
      gpu_task->get_pipeline_id(),
      gpu_task->get_task_id());
  }
} else if (reservation->size() < bytes_needs) {
  // No downgrade executor available -- warn and proceed (original behavior)
  SIRIUS_LOG_WARN(
    "GPU Pipeline Executor: Acquired memory reservation does not match requested size for "
    "pipeline {} of {} bytes needed for task "
    "{}. Reservation size: {}",
    gpu_task->get_pipeline_id(),
    bytes_needs,
    gpu_task->get_task_id(),
    reservation->size());
}
```

Key design points:
- Per D-01: Calls `request_free_memory_and_wait(shortfall)` where shortfall = bytes_needs - reservation->size()
- Per D-02: No delay between retries -- the blocking call IS the wait
- Per D-03: After 5 failed retries, proceeds with partial reservation and logs WARN
- Early break when freed == 0 (optimization: no point retrying if nothing was freed)
- Releases partial reservation before requesting downgrade (avoids pinning memory)
- Handles nullptr reservation after re-acquisition as error
- Falls back to original warning when _downgrade_executor is nullptr
