```cpp
bool downgrade_task::execute(rmm::cuda_stream_view stream) {
  auto memory_space = batch->get_memory_space();
  if (memory_space == nullptr || memory_space->get_tier() != cucascade::memory::Tier::GPU) {
    return false;
  }
  auto prev_state = batch->get_state();
  if (!batch->try_to_lock_for_in_transit()) { return false; }
  try {
    auto data_size   = batch->get_data()->get_size_in_bytes();
    auto reservation = res_mgr.request_reservation(
      cucascade::memory::any_memory_space_in_tier{cucascade::memory::Tier::HOST}, data_size);
    if (!reservation) {
      batch->try_to_release_in_transit(std::optional<cucascade::batch_state>{prev_state});
      return false;
    }
    auto mem_space = res_mgr.get_memory_space(reservation->tier(), reservation->device_id());
    if (!mem_space) {
      batch->try_to_release_in_transit(std::optional<cucascade::batch_state>{prev_state});
      return false;
    }
    auto& converter_registry = sirius::converter_registry::get();
    batch->convert_to<cucascade::host_data_representation>(converter_registry, mem_space, stream);
    batch->try_to_release_in_transit(std::optional<cucascade::batch_state>{prev_state});
    return true;
  } catch (...) {
    batch->try_to_release_in_transit(std::optional<cucascade::batch_state>{prev_state});
    throw;
  }
}
```

**Class 1: `convertible_data_batch` (inherits `sirius::convertible_data`)**

Constructor: `explicit convertible_data_batch(std::shared_ptr<cucascade::data_batch> batch)` storing the shared_ptr.

**`bool convert(const std::vector<cucascade::memory::memory_space*>& target_spaces, rmm::cuda_stream_view stream, sirius::memory::sirius_memory_reservation_manager& res_mgr) override`**

Per D-03 and D-04, generalize the `downgrade_task::execute()` pattern:

1. Save `prev_state = _batch->get_state()`.
2. Call `_batch->try_to_lock_for_in_transit()`. If fails, return false.
3. In a try block, iterate `target_spaces` in order:
   a. Get `data_size = _batch->get_data()->get_size_in_bytes()`.
   b. Request reservation: `res_mgr.request_reservation(cucascade::memory::specific_memory_space{space->get_tier(), space->get_id().device_id}, data_size)`.
   c. If reservation is nullptr, continue to next space.
   d. Get `mem_space = res_mgr.get_memory_space(reservation->tier(), reservation->device_id())`. If nullptr, continue.
   e. Determine target representation type by tier:
      - `Tier::HOST`: `_batch->convert_to<cucascade::host_data_representation>(converter_registry, mem_space, stream)`
      - `Tier::GPU`: `_batch->convert_to<cucascade::gpu_table_representation>(converter_registry, mem_space, stream)`
      - Other tiers: skip (continue)
   f. Where `converter_registry` is obtained via `sirius::converter_registry::get()`.
   g. On successful conversion: `_batch->try_to_release_in_transit(std::optional<cucascade::batch_state>{prev_state})` and return true.
4. If no target_space succeeded (loop exhausted): `_batch->try_to_release_in_transit(std::optional<cucascade::batch_state>{prev_state})` and return false.
5. In catch(...): `_batch->try_to_release_in_transit(std::optional<cucascade::batch_state>{prev_state})` then rethrow. This ensures BATCH-03 failure safety.

**`std::size_t bytes_in_space(cucascade::memory::memory_space* space) const override`**

Return `_batch->get_data()->get_size_in_bytes()` if `_batch->get_memory_space() == space`, else return 0.

Private member: `std::shared_ptr<cucascade::data_batch> _batch`.

**Class 2: `convertible_data_batch_provider` (inherits `sirius::convertible_data_provider`)**

Constructor: `explicit convertible_data_batch_provider(cucascade::shared_data_repository* repo)` storing the raw pointer.

**`std::unique_ptr<convertible_data> get_next_convertible(cucascade::memory::memory_space* space, bool front_to_back) override`**

Per D-01 and D-02:
1. Get `num_parts = _repo->num_partitions()`.
2. Iterate partitions. If `front_to_back` is false (the default use case per D-02), iterate from `num_parts - 1` down to 0. If `front_to_back` is true, iterate 0 to `num_parts - 1`.
3. For each partition, call `_repo->get_batch_ids(partition_idx)`.
4. Iterate batch IDs. If `front_to_back` is false, iterate from last to first. If true, iterate first to last.
5. For each batch_id, call `auto batch = _repo->get_data_batch_by_id(batch_id, std::nullopt, partition_idx)` to get a shared_ptr copy without state transition.
6. If batch is nullptr, skip.
7. Check: `batch->get_state() == cucascade::batch_state::idle && batch->get_memory_space() == space`. If matches, return `std::make_unique<convertible_data_batch>(std::move(batch))`.
8. If no match found across all partitions, return nullptr.

**`std::vector<std::unique_ptr<convertible_data>> get_all_convertible(cucascade::memory::memory_space* space, bool front_to_back) override`**

Same iteration as get_next_convertible but collects ALL matching batches into a vector and returns it.

**`std::size_t get_bytes_in_space(cucascade::memory::memory_space* space) const override`**

Iterate all partitions (0 to num_partitions-1), all batch_ids in each partition. For each batch retrieved via `get_data_batch_by_id(batch_id, std::nullopt, partition_idx)`, if `batch->get_memory_space() == space`, add `batch->get_data()->get_size_in_bytes()` to total. Return total.

Private member: `cucascade::shared_data_repository* _repo`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller -> convert() | Target spaces and reservation manager are caller-provided; batch state is shared mutable state across threads |
| provider -> repository | Repository is a shared mutable data structure accessed concurrently by multiple threads |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | T (Tampering) | convertible_data_batch::convert() | mitigate | Batch state is always restored via try_to_release_in_transit(prev_state) in all paths (success, failure, exception) per BATCH-03 — no path leaves batch in in_transit permanently |
| T-06-02 | D (Denial of Service) | convertible_data_batch::convert() | mitigate | Reservation failure causes graceful fallback (return false), not crash; exception in convert_to triggers state restoration before rethrow |
| T-06-03 | T (Tampering) | convertible_data_batch_provider iteration | accept | Provider reads batch state without locking — a TOCTOU race exists between checking idle state and caller locking for in_transit. This is acceptable because the caller's try_to_lock_for_in_transit() is the actual synchronization point (atomic state transition) and will fail safely if another thread changed the state |
| T-06-04 | I (Information Disclosure) | bytes_in_space() | accept | Returns byte count which is non-sensitive operational metadata; no PII or secrets involved |
</threat_model>
