Option A: std::hash over host-packed bytes. After cudf::pack the batch on GPU0, memcpy the packed bytes to a std::vector<uint8_t>, compute std::hash<std::string_view>{}(as_string_view(bytes)). Repeat after the return leg. REQUIRE the two hashes equal.

Option B: Simple byte-by-byte equality if the pack size is small (<1 MB). Use std::memcmp between two host-staged copies.

Option C (RECOMMENDED): Compute a 64-bit FNV-1a hash over the packed host bytes before and after. Simple, deterministic, no external deps. Inline helper:
```cpp
static inline uint64_t fnv1a64(const void* data, size_t len) {
  uint64_t h = 0xcbf29ce484222325ULL;
  auto const* p = static_cast<const uint8_t*>(data);
  for (size_t i = 0; i < len; ++i) { h ^= p[i]; h *= 0x100000001b3ULL; }
  return h;
}
```

    uint64_t compute_batch_checksum_fnv1a64(

        rmm::cuda_stream_view stream)

      uint64_t h = 0xcbf29ce484222325ULL;
