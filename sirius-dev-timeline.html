Sirius Development Timeline

Curated milestones from the dev branch of sirius-db/sirius, organized by architecture module. Sirius is a GPU-native SQL engine shipped as a DuckDB extension: it intercepts SQL transparently, converts DuckDB's plan into its own physical operators, groups them into pipelines, and a task creator turns "operator + available input" into GPU tasks run by a scheduler. Data flows between operators through repositories; ports tell each operator where its input lives.
